# PWA Icon Requirements

Please replace the placeholder icon files with actual PNG images:

## Required Icons:

1. **icon-192x192.png**
   - Size: 192x192 pixels
   - Format: PNG
   - Purpose: App icon for mobile devices and smaller displays

2. **icon-512x512.png**
   - Size: 512x512 pixels
   - Format: PNG
   - Purpose: App icon for larger displays and splash screens

## Optional Screenshots:

1. **screenshot-mobile.png**
   - Size: 390x844 pixels (or similar mobile dimensions)
   - Format: PNG
   - Purpose: Preview in PWA installation prompts (mobile)

2. **screenshot-desktop.png**
   - Size: 1920x1080 pixels (or similar desktop dimensions)
   - Format: PNG
   - Purpose: Preview in PWA installation prompts (desktop)

## Icon Design Tips:

- Use a simple, recognizable design
- Ensure good contrast
- Avoid fine details that may not be visible at smaller sizes
- Consider using the VlottrGG brand colors (#2563eb blue)
- Icons should work well with both light and dark backgrounds
- Use square images with transparent or solid backgrounds
